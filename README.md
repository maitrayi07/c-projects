# C Programming - First Year Fundamentals

Welcome to my repository of core programming concepts built during my first year! This repository tracks my journey in learning fundamental programming logic, mathematical series evaluation, conditional branching, and looping structures.

## 📁 Repository Structure & Included Programs

Below is the list of foundational programs implemented in this repository:

* **ARMSTRONG NUMBER CHECK** (`ARMSTRONG NUMBER CHECK.cpp`)
  * Extracts digits and checks if the sum of the digits raised to the power of the number of digits equals the original number.
* **BASE AND POWER** (`BASE AND POWER.cpp`)
  * An interactive calculator that evaluates \(a^b\) by multiplying a base number by itself a specified number of times using loop iteration.
* **FIBONACCI SERIES** (`FIBONACCI SERIES.cpp`)
  * Generates the iconic mathematical sequence where each number is the sum of the two preceding ones.
* **GREATEST OF THREE NUMBERS** (`GREATEST OF THREE NUMBERS.cpp`)
  * Demonstrates logical operator chaining and conditional branching (`if-else` blocks) to compare and find the largest input value.
* **INPUT MONTH NAME AND GET NUMBER OF DAYS** (`INPUT MONTH NAME AND GET NUMBER OF DAYS.cpp`)
  * Uses control structures or string mapping to take a month's name as user input and return the corresponding number of days.
* **PATTERN EASY LEVEL** (`PATTERN EASY LEVEL.cpp`)
  * Focuses on spatial layout logic and nested loop mechanics to print shaped geometrical patterns on the console window.
* **SUM OF SINE SERIES** (`SUM OF SINE SERIES.cpp`)
  * Approximates the value of the trigonometric Sine function by calculating the sum of its Taylor series expansion using complex loops.
* **TOTAL PRIMES TILL N INCLUDING N** (`TOTAL PRIMES TILL N INCLUDING N.cpp`)
  * An algorithm that evaluates all numbers up to a user-defined limit N to filter and print the complete sequence of prime numbers.

## 🚀 How to Run the Programs
1. Clone this repository to your local machine.
2. Open your choice of terminal (like Git Bash) inside the project directory.
3. Compile any source file using a standard compiler (like GCC or G++):
   ```bash
   g++ "FILENAME.cpp" -o program
   ```
4. Run the compiled executable application file:
   ```bash
   ./program
   ```
